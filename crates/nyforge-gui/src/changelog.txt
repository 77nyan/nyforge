## 0.1.91 | Installer shows the version
- Installing from a clone (`sudo ./install.sh`) is much faster: it downloads the released programs instead of compiling them.
- The installer now says which version it installs (read from the program itself), in the steps and at the end.

## 0.1.9 | NyForge in the terminal
- New: a full-screen terminal app. Run `nyforge -t` (or `--t`, `-terminal`).
- A menu on the left, one tool on the right: NyFlash, NyBoot, NyFormat and NyTest, plus the version history (click the version at the bottom of the menu).
- Same engine as the window, so the same safety rules: it never offers your system drive and asks before erasing.
- The installer is now a clean step-by-step screen: Install NyForge? Yes or No, choose what to install, then each step with a green check. It works with the mouse.
- `sudo ./install.sh` is the only way to install. `sh install.sh` and the like stop and say so.
- Light: about 4 MB of memory, and it only redraws when something changes.

## 0.1.82 | NyBoot and Secure Boot
- NyBoot says, when it installs or updates a drive, that Secure Boot has to be off to start it. A computer that lists the drive but starts its own system instead is blocking the unsigned boot files.
- README: the same note, with how to check.

## 0.1.81 | NyBoot menu text
- NyBoot menu text is smaller, so the list no longer looks oversized.
- Cleaner letters: the menu fonts are now fitted to the pixel grid.
- The version in Settings opens this history.

## 0.1.8 | exFAT fix
- Fixed: drives formatted as exFAT by NyForge now open in Linux file managers. Format old ones again.
- The version is shown at the bottom of Settings.
- Windows test build fixed.

## 0.1.7 | The huge update
- NyTest (optional): speed test, sustained write, surface scan, capacity check and drive health.
- Settings: reorder the start screen and switch NyTest on.
- NyBoot: new boot menu, custom themes, Memtest86+, bootloader update, per-image boot options.
- Windows media: smarter ISO detection and more install options. Faster writing and verifying.
- A calmer look, smoother animation, and a notification on Windows when a job ends.
- The Linux installer needs sudo. macOS is not available.
